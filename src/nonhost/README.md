# Non-host reads from datasets in SRA

## Features
- Input a list of SRA run accessions
- Output non-host reads as compressed FASTQ files
- QC reads and use four aligners to map/remove host reads
- Kallisto-based contamination pre-filter
- seq-detective barcode detection for scRNA-seq libraries
- Host gene count quantification (featureCounts or HTSeq)
- Distributed computing on HPC environments (SLURM job scheduler)
- Highly automated with dynamic resource allocation


## Usage

### Clone the repository
```
git clone https://github.com/czbiohub-sf/RNAquarium
```

### Install dependencies

The recommended approach is to run the pipeline with `-profile conda`, `-profile mamba`, `-profile docker`, or `-profile singularity`, which will automatically pull containers or environments for most steps. The conda/mamba option is preferred.

When using containers/conda, a small number of tools are not available as packages and must be installed locally:

- `fastq-lengths` — read length statistics
- `czid-dedup` — duplicate read removal
- `gmap-gsnap` — installed from source due to container issues

These can be installed with:
```bash
./setup-minimal.sh
```

### Set up and run
```
cd RNAquarium/src/nonhost
```

### Generating reference indexes
The nonhost pipeline needs reference genome information for mapping. There are two ways of providing this.

1. Pre-generated index directories (i.e. previously generated by each aligner). Provide the following parameters:
 - `--hisat-ref-indexes <hisat2 reference index path>`
 - `--star-ref-indexes-ercc <star reference genome index path>`
 - `--star-ref-indexes <star reference genome index without ERCC path>`
 - `--bowtie-ref-indexes <bowtie2 reference index path>`
 - `--gmap-ref-indexes <gmap/gsnap reference index path>`
 - `--ref-genome-gtf <reference.gtf>`

2. Reference genome assembly and spike-in sequences (indexes will be generated for you). Provide the following parameters:
 - `--ref-genome <primary_assembly.fa.gz>`
 - `--ref-genome-gtf <reference.gtf>`
 - `--ercc-fa <ERCC.fa>`
 - `--ercc-gtf <ERCC.gtf>`

The host reference genome, and *only* the host reference, must be `bgzip` compressed and indexed with `samtools faidx`.

For example, for the *Danio rerio* GRCz12tu genome assembly:
```
--ref-genome GCF_049306965.1_GRCz12tu_genomic.fa.gz
--ref-genome-gtf GCF_049306965.1_GRCz12tu_genomic.gtf
--ercc-fa ERCC92.fa
--ercc-gtf ERCC92.gtf
--genome-size 1448808683
```


### Running the main pipeline

Using a params file (recommended for production runs):
```bash
nextflow run main.nf -params-file params.yaml -profile slurm,mamba -resume
```

Or with inline parameters:
```bash
nextflow run main.nf \
  --ref-genome GCF_049306965.1_GRCz12tu_genomic.fa.gz \
  --ref-genome-gtf GCF_049306965.1_GRCz12tu_genomic.gtf \
  --ercc-fa ERCC92.fa --ercc-gtf ERCC92.gtf \
  --genome-size 1448808683 \
  --accession-list SRA_accession_list.test.txt \
  -profile slurm,mamba
```
